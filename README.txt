# Trabajo Práctico Final: Análisis Bioinformático y Estructural de Alfa-Hemolisina (9MBX)

## Descripción del Proyecto
Este repositorio contiene el desarrollo del trabajo práctico final, enfocado en la caracterización bioinformática de la secuencia primaria, análisis de motivos por expresiones regulares, scripting en Python y visualización estructural 3D del pre-poro heptamérico de la alfa-hemolisina de *Staphylococcus aureus* (PDB ID: **9MBX**).

## Estructura del Repositorio
- `rcsb_pdb_9mbx.fasta`: Archivo de secuencia FASTA obtenido desde RCSB PDB.
- `analisis_hemolisina.py`: Script modular en Python para la automatización del conteo de aminoácidos y detección de motivos mediante expresiones regulares (`re`).
- `results/`: Carpeta que almacena las capturas de alta resolución (2000x2000 px) generadas mediante UCSF ChimeraX.

## Herramientas Utilizadas
- **Terminal Linux (Ubuntu / WSL)** y Python 3 (`re`, `length`).
- **UCSF ChimeraX** para la inspección y renderizado estructural 3D.
- **Git y GitHub** para el control de versiones y entrega del proyecto.
